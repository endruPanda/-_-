# Telegram Mini App + Vapi.ai Voice Integration

Интерактивное Telegram Mini App с голосовым ИИ-ассистентом на базе Vapi.ai и динамической обработкой контекста через вебхуки.

## 🚀 Возможности
- Запуск голосового ассистента прямо внутри интерфейса Telegram.
- Передача идентификатора пользователя (`telegram_user_id`, `username`) на бэкенд для персонального ответа.
- Динамическая подгрузка контекста и памяти для ИИ в реальном времени.

## 🛠 Стек технологий
- **Фронтенд:** HTML5, CSS3, JavaScript (Vanilla)
- **Интерфейс:** Telegram Web App SDK
- **Голосовой движок:** Vapi SDK
- **Бэкенд и логика:** n8n Webhooks / API

## ⚙️ Как это работает
1. Пользователь открывает Telegram Mini App.
2. Приложение запрашивает данные профиля через Telegram Web App SDK.
3. При старте звонка Vapi связывается с бэкендом, передавая ID пользователя.
4. Система подтягивает персональную историю и контекст из базы данных, передавая их в промпт ассистента.
